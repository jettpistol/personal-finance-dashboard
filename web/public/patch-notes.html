What changed in each version

0.16.5 · Oct 29, 2026

  • Ajustes → Mercado Pago: a finished report that Mercado Pago lists as "enabled" (instead of "processed") is now downloaded. Before, the search waited on it until it gave up.
  • If Mercado Pago says a report failed, the search stops right away with that reason.

↑ Back to top

0.16.4 · Oct 29, 2026

  • npm start compiles the app first when the downloaded version is newer than the compiled one, and npm run update now compiles too. Before, a missing npm run build kept the old screens running.
  • When the code is newer than the compiled app, the yellow bar now says it needs compiling and how, instead of offering a Recargar that couldn't help.

↑ Back to top

0.16.3 · Oct 29, 2026

  • Ajustes → Mercado Pago: Buscando en Mercado Pago… could spin forever. Fixed three causes: a report file served through a redirect or taking more than 10 seconds to download, a report listed with slightly different dates than asked, and a slow report making the first import start over.
  • While it waits, a line says when it asked and what Mercado Pago answered last (for example "está preparando el reporte… (estado «pending»)"), with Cancelar.
  • It stops with the reason in red after 30 minutes, or after six checks in a row that couldn't reach Mercado Pago.
  • The server's terminal shows each step in lines starting with [mercadopago], without the token or the movements.

↑ Back to top

0.16.2 · Oct 29, 2026

  • One data folder for everything: npm start and the demo commands now both use server/data. Before, the demo commands used server/data-demo, so starting with npm start showed an empty app as if the users were gone.
  • On the first start, if server/data has no users and server/data-demo has some, they are copied over with everything else: profiles, movements, Mercado Pago connections, receipts and the encryption key. server/data-demo is kept as it was.
  • npm run data:recover brings the data-demo users back if server/data already had other ones. The folder it replaces is kept under a dated name.
  • Perfil de datos: deleting a profile keeps a full copy of it in the backups folder (backups/guardados). The window now says so.
  • npm run demo:reset keeps a copy of Prueba (demo) before reloading it.

↑ Back to top

0.16.1 · Oct 29, 2026

  • No changes in the app. Starting it (npm start, npm run demo:reset) and updating it (npm run update) first check the database driver and put it back when npm left it out, instead of stopping with "Could not locate the bindings file".

↑ Back to top

0.16.0 · Oct 29, 2026

  • Ajustes → Mercado Pago: new Movimientos line with Traer movimientos. The app asks Mercado Pago for its reports from the start date and shows Buscando en Mercado Pago… until they're ready.
  • The first import waits for a review (N para revisar → Revisar), in the same table as Importar. Nothing is saved before Importar.
  • The review can set the account's starting balance from Mercado Pago's own balance on the start date (Usar $ … como saldo inicial, ticked by default).
  • A withdrawal is marked Retiro and becomes a Transf. propia to the account you choose.
  • A movement you had already typed (same amount, at most a day apart) is marked Ya cargado and completed instead of added twice. It keeps your description, category and notes.
  • After the first review, new movements come in by themselves every hour. Only withdrawals wait for review, and rows you left out don't come back.
  • The Movimientos line shows Al día · HH:mm, a round arrow to update now, and the reason in red with Reintentar if something fails.
  • New Saldo line: your balance according to Mercado Pago, and En la app: $ … when the app's balance is different.
  • If the reports have no settings in Mercado Pago, or older settings without the amount columns, the app saves or widens them before asking.
  • Cuentas: your Mercado Pago account has a green tag with a pulsing dot: Conectada, then En vivo with actualizado HH:mm under Saldo, or Sin actualizar (orange) after a failure. Only you see it.
  • Movement form: new optional Comisión part, for fees a platform (Mercado Pago or any other) kept from the movement. The amount stays what really moved; fees can't exceed it.
  • Movimientos: a Comisión $ … line under the amount of movements with fees.
  • Reportes → Comisiones: new tab with fees per month and per platform, by kind.
  • Actividad records each Mercado Pago review and each automatic import.

0.15.0 · Oct 28, 2026

  • New Resúmenes section: upload a bank PDF or Excel file as the bank gives it and the app recognises the format by its content.
  • Reads Banco Galicia's Caja de Ahorro extract (Excel) and monthly statement (PDF), and the Visa and American Express card statements (PDF).
  • Checks that the numbers add up to the totals the document prints itself. A file that doesn't add up is not imported.
  • Rows go through the same review as Importar, and the import can be undone from its Historial.
  • Card payments and the conversion of a USD debt start unticked, because the payment is already recorded from the bank account. Dollar purchases stay in dollars.
  • Card installments show cuota X/Y and are dated on the statement's close date; the purchase date is kept in the note.
  • Categories come from your rules first, then from the suggested rules bank (marked Sugerida). Merchants in neither stay without a category. Card interest, taxes, salary and refunds get a fixed category.
  • The suggested rules bank now also recognises Uber Eats, Crunchyroll, Patreon, LinkedIn, Solo Deportes, neighbourhood supermarkets, fruit shops, Granja, and the shortened names card statements print (SportClub, Burger King, Cencosud Easy, pet shops).
  • Importar can now open the Excel extract that Galicia exports, which it couldn't read before.
  • New help article: Resúmenes. The Docker image now includes pdftotext, needed to read PDFs.

0.14.0 · Oct 28, 2026

0.12.0 · Oct 28, 2026

  • New Actividad section in the sidebar: a log of every change that affects your numbers, with who made it.
  • Filter the log by section (with counts), person, date range or text, across this profile or all profiles; click an entry to see what changed, before and after.
  • Times show in Argentina time by default, or any time zone you pick; the exact UTC time is in each entry's details and in the CSV download.
  • Clear one section, entries before a date, or everything from the ⋯ menu; each clearing is recorded too.
  • The log is kept across updates and profile resets. Entries about private accounts, Deudores, Pendientes and your own settings are only visible to you; passwords and tokens are never recorded.
  • "Pagos pendientes" is now Pendientes, with two separate lists, Pagos and Cobros, each with its own counter. The sidebar counter is their sum.

  • One Registrar button: it asks whether to pick a movement already loaded or to load a new one. A new one is tied to the item when saved, whatever the amount.
  • Fixed: paying a dollar savings plan with a peso conversion, or registering a partial payment or collection, did nothing. Short amounts now ask why and say how much is still missing.
  • "incluye X del mes anterior" is now "+ X del mes anterior"; payments no longer show "(automático)".
  • A commitment due on the 29th, 30th or 31st falls on the last day of shorter months.
  • Dollars are written USD everywhere, never US$. Amount boxes only show the $ sign; the currency is shown once, next to it.
  • In every dropdown, the tick of the selected option sits at the end, so the names never move.
  • Mercado Pago: the connection fills one account in Cuentas per person. It creates "Mercado Pago" if you have none; if you already have one, it asks which and can't be skipped. A second Mercado Pago account is refused.
  • Mercado Pago history starts on 1 October 2026 unless you change it.

0.8.0 · Oct 27, 2026

New: Pagos pendientes

  • For commitments you carry out yourself: monthly savings (e.g. US$ 200 to the savings account every 6th), debts you pay back, and loans from Deudores with a date or installments.
  • A movement with the exact amount, in the same currency, is linked by itself when you save, import or load it from a CSV. Registrar opens the form already filled in; Vincular picks an existing movement.
  • Partial payments need a written reason. What's missing rolls over to next month; paying extra lowers it.
  • Reminders every day from 8 to 18 (around 8, 12 and 16), in the bell and by email, only to whoever is responsible, until it's done.
  • Red counter next to Pagos pendientes in the sidebar.

Deudores

  • Con interés o en cuotas when lending money: monthly interest (or last month's inflation with one click), number of installments and first due date, with the total calculated.
  • Interest, installments, amount and dates are fixed once the loan is saved.
  • A partial return needs a reason. An income with exactly the installment amount is recorded as a return by itself.

Email setup in Ajustes

  • Ajustes → Notificaciones has a card for the account that sends the emails: Gmail address and app password, Guardar and Probar, without editing any file.

Help wiki

  • Ayuda in the footer opens the user guide as a wiki, in the style of Apple's developer help, with search and dark mode. Includes a new article on setting up email.

Other

  • Date fields accept typed dates (e.g. 27/11/2026), not only picking from the calendar.

0.7.0 · Oct 27, 2026

Email notifications

  • Alerts (budgets, items to confirm, the monthly .docx review) can now arrive by email. Free with a Gmail app password.

Suggested rules

  • "Aplicar reglas a movimientos sin categoría" is now just Aplicar reglas (the explanation is in its tooltip).

0.6.0 · Oct 27, 2026

New: Deudores

  • A section to note money and things you lend: who, how much (or what), when, and by when it should come back.
  • Partial returns with a progress bar; the loan closes itself when it's fully paid. You can also forgive the rest or reopen it.
  • Totals of what you're owed (pesos and dollars), things lent, and overdue loans in red.
  • Recordar copies a friendly message listing what that person still has, ready for WhatsApp.
  • It isn't linked to accounts or reports yet, and each of you only sees your own list.

General

  • Switch account: from the user menu, Agregar cuenta logs your partner in too, and one click switches between you without a password. Cerrar sesión only logs out the account in use.
  • Pop-up messages have the close button on the left and the colored bar on the right.
  • Dropdowns with groups (Cuenta, Categoría): group titles span the full width and open or close their entries. Only the group of the selected entry starts open; typing searches all of them.

Movimientos

  • Importar CSV in Nuevo movimiento: load many movements from one file, with a downloadable example, a row-by-row check and repeated rows skipped.
  • Cobro en cuotas: income in installments. Each cuota stays pending (money to collect) until you confirm it was paid; due ones appear in the yellow alert.
  • "Transferencia" is now Transf. propia, to tell it apart from paying someone.
  • The board filter is called Tablero: Hogar / Tablero: Iván / Tablero: Milagros, and hides the Compartido / name tag while it's on.

Cuentas

  • A list on the left (Todas, Compartido, Iván, Milagros) picks which accounts show; cards are grouped by owner on the right.

Other

  • Perfil de datos: no more "Por defecto" tag.
  • Test data: shared income (garage rent, health insurance refund), interest, sales, a sale in 3 cuotas, and sample loans in Deudores.

0.5.0 · Oct 26, 2026

Presupuestos

  • Ajustar por inflación is now a checkbox instead of a button. Ticked, peso budgets are shown adjusted by the inflation published since you set them; unticked, as you entered them. Ticking it again never adds inflation twice.
  • The same checkbox replaces the automatic option in Ajustes → Hogar, which also compounded.
  • Each budget card says how much inflation it includes, e.g. "incluye +7,4% de inflación".
  • Budgets turn red above 95% (before: at 100%), here and on Inicio.
  • Removed the "por día" amounts and the "Pasó el …% del mes" line.

Movimientos

  • Every movement has a tag saying whose it is: Compartido, Iván or Milagros. Shared movements and anything in a joint account are Compartido.
  • The Hogar / Mío / Milagros tabs now filter the list by that tag: Hogar shows the shared ones, each person's tab shows their own. Turn off Solo del tablero seleccionado to see everything.
  • For shared income, the tooltip says who received it instead of "Pagó".

Reportes

  • "IPC últimos 12 meses" is now Inflación interanual.

Perfil de datos

  • Changing profile keeps you on the page you're on and reloads its data, from both the top bar and the Perfil de datos page.
  • The "En uso" column header is gone; the column stays.
